HTTP interface

GET /health

Liveness probe used by load balancers and this console.

GET /health/ready

Readiness probe for deployment orchestration.

POST /webhooks/twilio/voice

Twilio Voice webhook — signature validated, returns TwiML.

POST /webhooks/vapi

Vapi server URL for tool-calls, status updates, and end-of-call reports.

GET /tools/definitions

Machine-readable tool schemas to paste into the Vapi assistant.

POST /tools/:toolName

Direct tool execution endpoint for discrete Vapi custom tool URLs.
